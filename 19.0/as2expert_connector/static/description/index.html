AS2Expert Connector

Send and receive files over AS2 straight from Odoo — no AS2 server, no certificates to babysit.

This addon turns Odoo into a generic AS2 mailbox backed by the AS2Expert cloud platform. AS2Expert does the hard part — signing, encryption, MDNs, certificate management and partner connectivity. Odoo just exchanges files through the documented REST API and reacts to webhooks.

It is transport-generic: it moves EDIFACT, X12, XML, PDF or any payload, and does not parse document content. Pair it with your own EDI mapping or with AS2Expert's built-in EDIFACT tooling.

📤 Send in one click

Attach a file, pick a partner, press Send over AS2. The AS2 Message-ID comes back on the record.

📥 Reliable inbound

Real-time webhook plus a 5-minute polling fallback, de-duplicated by API id. Nothing is missed if a webhook is dropped.

🤝 Partner sync

Import the partners defined in your AS2Expert station with one click.

🔒 Guarded webhook

Unguessable per-account token in the URL and optional HMAC-SHA256 verification of the request body.

How it works

  1. Create an Account with your AS2Expert API base URL and token.
  2. Test connection and Sync partners.
  3. Register the account's Webhook URL in the AS2Expert console.
  4. Send files to partners; inbound messages arrive automatically with the file attached.

The webhook is only a trigger: it authenticates the caller and then runs the same inbound poll used by the scheduler, which pulls messages from the REST API. That makes inbound delivery robust and idempotent.
